## 📊 Project Overview
A comprehensive business intelligence solution that analyzes pizza sales data to uncover trends, identify top-selling products, and provide data-driven insights for optimizing sales strategies and driving business growth.

## 🛠️ Technologies Used
- **BI Tool**: Microsoft Power BI
- **Data Processing**: Power Query
- **Database Analysis**: SQL Server
- **Data Source**: Excel
- **Programming**: SQL, DAX

## 📈 Dashboard Features

### 🏠 Home Dashboard
- **Executive KPIs**: Total Revenue, Orders, Pizzas Sold, Average Order Value
- **Trend Analysis**: Daily & Monthly order patterns with interactive charts
- **Revenue Distribution**: Donut charts for pizza categories and sizes
- **Sales Performance**: Bar charts showing pizza volume by category

### 📋 Best/Worst Sellers
- **Top 5 Analysis**: Pizzas ranked by Revenue, Quantity, and Total Orders
- **Bottom 5 Analysis**: Underperforming pizzas for improvement opportunities
- **Performance Metrics**: Comprehensive product performance evaluation

### 🎯 Title Page
- **Professional Introduction**: Project overview and navigation
- **Interactive Navigation**: Seamless transitions between dashboard pages

## 🎯 Key Insights Discovered

### Sales Performance Metrics
- **Total Revenue**: $817.9K from 21,350 orders
- **Total Pizzas Sold**: 49,574 units
- **Average Order Value**: $38.31
- **Average Pizzas per Order**: 2.32

### Business Intelligence Findings
- **Peak Sales Days**: Weekends (Friday/Saturday) show 15% higher sales
- **Seasonal Trends**: Maximum orders in July and January
- **Top Category**: Classic pizzas contribute 26.9% to total revenue
- **Popular Size**: Large pizzas drive 30.5% of total revenue
- **Customer Behavior**: Average of 2.32 pizzas per order indicates group purchases

## 🚀 Getting Started

### Prerequisites
- Microsoft Power BI Desktop (Free Download)
- Microsoft Excel
- SQL Server (for running analysis queries)

### Installation Steps
1. **Download the project files** from this repository
2. **Open Power BI Desktop** and load `PowerBI-Dashboard.pbix`
3. **Explore the interactive dashboard**
4. **Run SQL queries** from `/SQL/pizza_analysis_queries.sql` for detailed analysis

### Using Your Own Data
1. Replace the sample data in `Data/pizza_sales_data.xlsx`
2. Update data source in Power BI (Home → Transform Data → Data Source Settings)
3. Refresh the dashboard
